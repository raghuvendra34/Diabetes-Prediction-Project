# Diabetes Prediction Using Machine Learning

This project predicts whether a person is diabetic or non-diabetic using Machine Learning techniques.

## ** Deployed App **
 [Click here to try  the app(https://diabetes-prediction-project-34.streamlit.app)

## Technologies Used
* Python
* NumPy
* Pandas
* Scikit-learn
* Support Vector Machine (SVM)
* Streamlit
* Google Colab

## Features
* Data preprocessing
* Model training using SVM
* Accuracy evaluation
* Diabetes prediction system
* Interactive web application

## Dataset
PIMA Indians Diabetes Dataset

## Project Workflow
1. Import dependencies
2. Load and analyze dataset
3. Data preprocessing
4. Train-test split
5. Model training
6. Model evaluation
7. Prediction system
8. Web app deployment using Streamlit

## Accuracy
* Training Accuracy: ~78%
* Testing Accuracy: ~77%
