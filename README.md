# Diabetes Prediction Using Machine Learning

This project predicts whether a person is diabetic or non-diabetic using Machine Learning techniques.

## Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Support Vector Machine (SVM)
* Google Colab

## Features

* Data preprocessing
* Model training using SVM
* Accuracy evaluation
* Diabetes prediction system

## Dataset

PIMA Indians Diabetes Dataset

## Project Workflow

1. Import dependencies
2. Load and analyze dataset
3. Data preprocessing
4. Train-test split
5. Model training
6. Model evaluation
7. Prediction system

## Accuracy

* Training Accuracy: ~78%
* Testing Accuracy: ~77%
